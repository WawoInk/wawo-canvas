# 待测试

- 企业积分流水：企业主账号可在账户设置中分页查看主账号和当前成员的平台调整、企业分配/收回、AI 消费/退款流水，并按成员、类型和关键词筛选；子账号仍仅能读取自己的个人流水，跨企业成员 ID、企业 ID 和关键词不能扩大查询范围。
- 企业文本素材库：有效企业的主账号和成员可分页搜索、按类型和标签筛选并预览本企业文本素材；主账号可新增、编辑和删除，成员只读，个人用户和跨企业账号无法读取或修改；企业素材不进入个人素材缓存、增量同步或 WebDAV。
- 企业媒体素材授权：主账号可上传、替换和删除本企业图片/视频素材及关联文件，主账号和成员可预览、读取和下载；个人文件与企业文件互不穿透，企业 A/B、个人用户、成员写入越权、猜测 ID、企业/成员停用和预签名 URL 均有 HTTP 集成覆盖，响应不包含原始 S3 Key。
- 企业素材服务端复制：企业主账号和成员可把文本、图片和视频加入“我的素材”；文本生成独立个人素材，媒体生成新的个人文件和个人素材，复制后的 `fileId` 不复用企业文件；跨企业/个人账号拒绝，源素材删除、企业停用后恢复或用户离开企业后个人副本仍可读，媒体复制失败或数据库事务失败不留下个人记录和对象。
- 企业积分划拨：企业主账号可在成员列表按正整数分配或收回积分，并立即看到双方余额；相同请求 ID 只记账一次，余额不足、跨企业/非主账号操作、并发划拨、生成扣费竞争和事务失败均不会产生负数、超发或单边流水。
- 企业成员管理：企业主账号可在账户设置中分页搜索、创建、启用、禁用和重置本企业子账号密码；成员初始积分为零，禁用与密码重置立即作用于会话，子账号、个人用户、平台管理员和其他企业账号不能执行成员管理。
- 账号数据隔离：同一浏览器依次登录企业 A、企业 B 和个人账号时，Canvas、个人素材、同步游标、工作台历史及受保护查询不会展示上一账号数据；退出和认证失效同样立即清空内存视图。
- 企业基础管理：平台后台可创建和搜索企业、查看主账号/成员数/余额、分别切换企业与主账号状态并重置主账号密码；企业禁用立即拒绝全部成员会话，单独禁用主账号不影响成员，重置密码后旧 JWT 失效。
- 企业充值：平台管理员可在企业管理中按增量增加或扣减主账号积分，余额不足时不落库；余额与带原因、操作者和目标账号关联的流水在同一事务提交，企业页可立即核对余额和最近平台调整，用户列表显示企业归属与企业身份。
- 账户设置：头像菜单可进入账户设置，所有登录用户可查看用户名、积分和平台身份并修改昵称、邮箱和自己的密码；“日志记录”页签可分页查看当前账号自己的操作类型、来源、模型、状态、耗时、积分消耗和积分变动流水，传入其他用户 ID 不能扩大查询范围或读取其任务详情；企业主账号与成员可查看企业概况，仅主账号可改企业名称，有效企业账号的桌面与移动导航显示“企业素材库”，个人账号直接访问时由服务端拒绝。
- Codex App 插件文档：新增插件安装教程，区分 AI 自动安装、手动安装和本仓库开发调试安装；同步优化插件 README 与技能说明。
- 配置与用户偏好：每个模型渠道新增 OpenAI / Gemini 调用格式选择，默认 OpenAI，切换默认格式时同步更新默认 Base URL；渠道 Tab 增加紧凑醒目的提醒，说明模型是否可选需要到“模型”Tab 选择。
- Gemini 调用格式：支持拉取 Gemini 模型列表，并用于文本问答、在线 Agent 工具调用、基础生图和图生图请求。
- 音频和视频生成：选择 Gemini 调用格式时先给出不支持提示，仍需使用 OpenAI 兼容渠道。
- 第一方视频生成：生成节点区分“排队中”和“生成中”，刷新或停止本地等待后可沿用同一平台任务恢复查询；异步失败保留可定位的设置或资源错误。
- 生成任务可靠性：上游成功但缺少视频结果会稳定失败并一次退款；回调、轮询、取消和超时不会覆盖已进入结算或终态的任务。
- 图片生成：共享图片设置新增透明背景开关，同步生成、同步编辑、Canvas 异步生成/编辑和 Retry Run 均按本次 Generation Run 快照传递；Resume Observing 不重复提交。
- Canvas Prompt：普通节点支持文本与资源 chip 混合编辑，保留原有字符串标签、active resource 顺序和连接关系，并支持 IME、纯文本粘贴、原子删除、撤销重做及键盘资源菜单。
- Canvas 输入光标：画布节点中的提示词和配置编辑器移动鼠标时显示文本输入光标，不再继承画布的抓手光标。
- Canvas 总览：桌面左侧新增可折叠 Canvas / Assets 侧栏，支持节点搜索、类型过滤、状态、图片与视频首帧缩略图、批量根归并、聚焦选择，并在素材插入和项目重载时保留 `fileId` 关联。
