# 待测试

- 图片请求一致性：同步生成、编辑、异步创建及 Gemini 图片请求使用 10 分钟请求超时，同时保留调用方取消；超时显示明确提示。远程 OpenAI→Gemini 转换同样依据明确的像素尺寸发送 `imageSize`，不要求模型名包含版本，也不从 `quality` 推导分辨率；`auto` 尺寸继续由上游决定。公开图片 API 与模拟上游 HTTP 回归已覆盖；请人工确认真实自定义模型、长请求及手动取消。

- 增量同步 HTTP 回归：新用户首次 `GET /api/v1/sync` 不传时间游标也可正常返回空数组；素材更新与删除记录只返回当前账号的数据。删除时间保留数据库的小数秒精度，素材、任务与删除游标按实际时间比较；原样传回响应游标时不重复返回旧记录。独立 PostgreSQL 17 的永久 HTTP 回归覆盖冷启动、账号隔离、更新/删除与游标重放，Canvas 仍使用独立 revision 游标；请人工确认新浏览器首次登录及删除素材后的连续同步。

- upstream v0.20.0 合并：画布节点面板和创建菜单在缩放时保持屏幕尺寸；选择参考时提示固定在视口顶部并隐藏节点悬浮工具栏；复制或粘贴节点保留入站参考，已删除的参考源不产生悬空连接；节点聚焦考虑设置面板、悬浮工具栏及底部工具栏，并提供居中按钮和默认关闭的选中自动居中偏好。图片支持 `xhigh/max` 质量且质量不再改变尺寸；Gemini 明确选择像素分辨率时按所选分辨率发送 `imageSize`；失效的本地渠道模型保留选择并阻止请求，不自动改用其他模型。请人工确认浅深色主题、极小视口、真实模型及跨设备恢复。本次保留本地 Canvas/Agent/文档目录、平台生成与计费、账号隔离、Replica 同步、许可证、版本号和手动部署流程；上游原位重新生成涉及本地持久结果与批次隔离，继续采用本地新节点生成逻辑。

- 生成结果上传限额（#72）：图片、视频、音频的 `results/*` 上传与普通媒体使用相同管理员限额，超限在存储请求前拒绝，等于上限可上传并读取。真实 HTTP、PostgreSQL 和本地 S3 fixture 已覆盖；请人工确认工作台与画布超限提示。
