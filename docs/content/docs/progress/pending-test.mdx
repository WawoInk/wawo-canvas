# 待测试

- Canvas Prompt：普通节点支持文本与资源 chip 混合编辑，保留原有字符串标签、active resource 顺序和连接关系，并支持 IME、纯文本粘贴、原子删除、撤销重做及键盘资源菜单。
- Canvas 节点发送快捷键：节点提示词输入框改为回车换行、`Shift+Enter` 发送，避免普通回车误触生成。
- Canvas 视频资源引用：视频节点连接到其他节点后，在提示词输入框输入 `@` 时，候选项和插入后的资源 chip 使用对应视频节点的同一视频地址显示首帧，不再出现破碎图片。
- Canvas 节点输入：提示词与配置编辑器中的资源 chip 使用真实 DOM 排版，后续文字、换行和粘贴内容的光标紧贴实际字符；文字节点使用单一原生 textarea，不再叠加会与真实 caret 产生宽度差的高亮镜像层；节点提示词输入框可正常使用滚轮上下滚动，且不会触发画布缩放。
- Canvas 节点输入放大：节点提示词输入框右下角新增放大/缩小按钮；插入 `@` 资源后切换尺寸会保持焦点和光标选区，缩小后继续保留完整内容并用于后续生成请求。
- Canvas 输入光标：画布节点中的提示词和配置编辑器移动鼠标时显示文本输入光标，不再继承画布的抓手光标。
- Canvas 总览：桌面左侧新增可折叠 Canvas / Assets 侧栏，支持节点搜索、类型过滤、状态、图片与视频首帧缩略图、批量根归并、聚焦选择，并在素材插入和项目重载时保留 `fileId` 关联。
