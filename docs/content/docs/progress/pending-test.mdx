# 待测试

- 图片/视频工作台任务对齐：远程生图工作台改用与 Canvas 图片节点相同的异步 compatibility task 提交、轮询和 `results/images` 物化流程，平台文件保存并校验属于当前用户后才进入成功；运行中可主动取消，失败、取消、轮询超时和服务端物化等待超时均只退款一次。远程视频工作台只观察平台 compatibility task，不再与服务端重复轮询上游，成功后按平台返回的 `fileId` 展示结果，取消仍使用上游 task ID 交给 compatibility 路由结算。两个工作台与 Canvas 都读取系统设置投影的同一模型配置；任务日志必须先落库再启动请求，落库失败不扣积分也不请求上游。重点验证图片生成/编辑成功、批量部分失败、主动取消、刷新历史，以及视频成功、失败、取消和刷新后继续观察；真实浏览器、IndexedDB、预签名文件访问和本地 `7897` 外部代理由人工验证。
- 多窗口账号切换隔离：同一浏览器的窗口 B 退出并登录另一账号后，仍停留在旧账号 Canvas 的窗口 A 会立即离开旧项目页面并按共享登录态重新加载；窗口 A 在收到切换事件前发起的图片、视频或音频上传仍使用窗口 A 当时的账号，上传过程中发生账号变化时不会把返回的 `fileId` 写入新账号画布。文件下载、预签名 URL 刷新、素材文件删除和管理后台素材上传也统一使用当前窗口已确认的登录态，不再直接读取可能已被其他窗口改写的认证缓存。
- 模型算力点与私有渠道联动：管理后台“系统配置 > 私有配置”取消选择模型并保存后，“公开配置 > 模型算力点”不再显示或保留这些模型的价格；仍被启用渠道选中的模型及其启用 Generation Profile 定价保持不变。
- 网站国际化：前台、账户、素材、提示词、图片/视频工作台、配置、管理后台和 Canvas 支持 `zh-CN` / `en-US`；页面 URL 统一显示 `/zh-CN/...` 或 `/en-US/...`，无语言前缀地址会按当前语言补全，切换语言时保留当前页面、查询参数和 hash 且不刷新页面。用户选择保存到浏览器并在刷新后保持，URL 语言前缀优先决定当前语言；登录守卫、SEO、顶部导航和后台菜单按去除语言前缀后的应用路径判断，带语言前缀的登录页不会循环重定向。浏览器语言、Ant Design、Day.js、日期/数字/高精度积分、复数、`html lang`、页面标题和 meta description 会随当前语言更新。
- 视频能力绑定 Metadata：管理后台“私有配置 > 视频能力绑定”的所有画布能力均可配置任意字符串 Key/Value；创建 Generation Run 时平台会快照该配置，并在请求上游时封装为 `metadata`。Sora 的 `action` 由管理员配置并原样透传，便于后续扩展；画面比例、参考视频和参考音频等平台生成字段会与管理员 Metadata 合并，并以当前 Generation Run 的实际输入为准。
- 普通视频（Sora）：管理后台“私有配置 > 视频能力绑定”可新增“普通视频（Sora）”并绑定渠道中的实际模型，支持分辨率可选 `480p`、`720p`、`1080p`；Canvas first-party 普通视频使用 JSON 调用 `POST /v1/videos`，请求发送绑定的实际上游模型、`prompt`、`duration`、`size` 和管理员配置的 `metadata.action`，不会按图片数量自动推断 action。图片放在顶层 `images`，画面比例、参考视频与音频分别放在 `metadata.aspect_ratio`、`metadata.video_urls`、`metadata.audio_urls`。轮询 `GET /v1/videos/{task_id}` 支持从顶层 `url`、`output.url` 或 `metadata.url` 提取结果，随后下载并上传到 S3，Canvas 只使用平台 `fileId`；沿用现有任务、计费、结果物化和恢复观察语义，不提供取消。
- 图片请求格式与分辨率：管理后台“系统设置 > 公开配置”可按当前图片模型选择 `默认`、`application/json` 或 `multipart/form-data`，并复选图片请求分辨率 `default`、`1k`、`2k`、`4k`；配置行的图片模型、请求格式、画布调用方式和分辨率显示对齐的顶部标题。`default` 表示不限制并与显式档位互斥，空值或仅含非法值时归一化为 `default`，重复值会去重并按 `1k`、`2k`、`4k` 排序。其中请求格式的 `默认` 不覆盖平台调用方式：生成入口使用 JSON，编辑入口使用 multipart。并可配置“我的画布”按场景分端点或统一使用 generations。默认模式下，无参考图走 generations，有上传图片或连线图片走 edits；统一模式下，有图请求也走 generations，单图发送 `image` 字符串，多图按画布顺序发送 `image` 数组，最多 9 张，并继续传递 `prompt`、`size`、数量、透明背景和输出格式等现有参数。远程 Canvas 与生图工作台的共享图片设置会合并所选档位的已有选项：`default` 保留全部，`1k` 提供七个基础比例，`2k` 提供 `2048x2048`、`2560x1440`、`1440x2560`，`4k` 提供横竖两个 4K 预设；节点模型优先于全局图片模型，设置浮层未打开时生成边界仍会把失效旧预设归一到同方向尺寸，合法自由宽高保持不变。`Images` 的 JSON 编辑按 `images[].image_url` 发送引用，其他模型沿用 `image` 字符串或数组；默认 multipart 编辑会通过画布素材的 `fileId` 读取真实图片字节，避免把 S3 URL 误转成空文件。本地环境已将 `gpt-image-2-open-1-edit` 配置为 `application/json`。
- 生图工作台异步任务：文生图和图生图统一走异步 create/query/terminal 流程，每个批次 slot 保存 source、上游 task ID、平台 task ID、模型、终态和 `fileId`。刷新或离开页面后继续观察原任务，不重复创建；失败卡重试会更新原 slot 的新任务身份；远程取消会发送真实上游 task ID 与模型，未获确认时保留 pending 供恢复；删除批次会删除全部唯一平台任务记录。代理返回的查询包装错误、临时网络错误和结果上传错误只暂停观察并保留恢复身份，只有供应商明确 `failed/cancelled` 才写入终态失败。
- 图片异步任务协议：Canvas 图片生成和编辑提交后优先读取上游响应顶层 `id`，并使用该值轮询 `/tasks/{id}`；若提交响应已直接返回顶层 `data[]` 或 `result.data[]` 中的 `b64_json` 或 `url`（包括 `status: "completed"` 的任务响应），则不再继续轮询，而是立即沿用 `results/images` 上传流程保存到 S3 并把平台 `fileId` 写回图片节点。轮询收到 `status: "completed"` 时仍从 `result.data[]` 或顶层 `data` 解析结果。
- 图片异步失败结算与日志：提交返回上游任务 ID 后，平台任务保持运行中，直到轮询得到成功、失败或取消终态；失败/取消会在同一终态事务中仅退还一次本次积分，重复轮询不会重复退款。任务日志保留图片类型、Canvas 来源、Provider、模型、实际积分、上游任务 ID、耗时、错误码与错误消息，并在详情中记录请求正文、最终响应正文/响应头和原始错误。重点验证 `Dola-Seedream-5.0-lite` 使用低于 2K 的分辨率失败后余额恢复且只有一条退款流水，同时 `Images` 成功生成仍正常完成并记录成功终态。
- 平台模型显式开放：管理后台“各能力可选模型”成为图片、视频、文本和音频模型的唯一公开来源，留空时该能力无模型可选；我的画布、生图工作台和视频创作台会过滤未勾选模型并替换失效的旧默认选择，服务端模型 Profile 与生成入口也会拒绝未显式开放的模型。
- 管理后台用户管理：用户列表新增“用户 ID”列，长 ID 单行缩略，悬停可查看完整值并支持一键复制；宽表格的横向滚动限制在表格内部，不再撑宽页面或造成右侧错位。
- 管理后台使用日志：按用户 ID、任务类型和“成功”筛选时，会同时返回底层状态为 `success` 与 `succeeded` 的全部成功记录；算力点日志及企业积分流水的组合筛选保持完整结果。
- 管理后台日志日期筛选：算力点日志和使用日志新增日期范围选择，按本地首日开始时间与末日结束时间查询并在清空时回到全部记录；算力点日志新增用户名列，展示每条记录当前对应用户的用户名。
- 管理后台失败任务退款修复：在“使用日志”详情中，失败或已取消且缺少退款流水的任务显示“补发退款”操作；管理员填写原因后，服务端应将原消费金额退回实际扣费账号（包括企业子账号），重复提交不增加余额，正常已退款任务和运行中任务不提供或不接受补发操作。
- 模型展示名：管理后台“公开配置 > 模型算力点”可为每个模型填写展示名称；账户设置的使用记录和管理后台使用日志均新增“模型展示名”列，未填写时显示上游模型名。新产生的 AI 消费和失败返还积分备注也显示展示名称，模型选择与请求转发仍使用原始上游模型名。
- Canvas 强持久化：新增/删除节点、编辑内容、连线、配置和视口等业务修改会按账号串行写入 IndexedDB Replica，旧异步快照不能覆盖新快照；服务端创建、更新和删除只会读取已完成本地 durable write 的状态，本地写失败时不会被后台 retry 越过。生成视频成功结果会先把 `fileId`、成功状态和媒体元数据 durable commit 到 Replica，再在页面中视为完成。重点验证包含至少 120 个图片/视频/音频节点的大画布：阻塞本地写、保持普通 PUT 在途后立即关闭并重新打开，仍能从 dirty Replica 恢复，不依赖 `beforeunload` 或 keepalive；现有断网重试、revision/localVersion、409 冲突、创建响应丢失、删除 tombstone 和账号隔离语义保持不变。
- Canvas 视频积分展示：远程视频模型按分辨率每秒计费时，普通视频节点和视频配置节点的生成按钮会按当前分辨率单价乘以所选时长展示积分；例如 `720p` 为 2 点/秒、时长 6 秒时显示 12 点。按次或按上游 credits 计费的模型继续显示原有标量价格，本地直连仍显示 0 点。
- Codex 生命周期自动化：项目级 `UserPromptSubmit` hook 会在每个任务开始前读取 `.knowledge/index.md`，按任务关键词最多加载 3 个相关知识文件，并记录本轮工作树基线；`Stop` hook 只对本轮改动执行路径与结构规则筛选，命中新增模块、架构、API 或数据结构变化时才启动只读的独立 Memory Update Agent，校验后仅允许写入 `.knowledge/*.md`。需要在 Codex `/hooks` 中信任项目 hooks 后，分别验证普通 bug 修复不会调用 Agent、结构变化会按现有知识库结构更新 Markdown，且任何 hook 失败都不影响任务结束。
- 积分余额动态同步：当前页面完成后端生成扣款、失败退款或积分调整后，会自动刷新共享用户余额；顶部余额、账户设置和积分记录等所有读取当前账号积分的位置无需手动刷新即可同步更新，Canvas 文本流与异步生成轮询同样覆盖。
- 企业折扣倍率与小数计费：管理后台“企业管理”可为每家企业设置 `0.1-1` 的折扣倍率，新企业默认 `1`；企业主账号在账户设置的企业概况中可查看当前倍率。企业主账号和成员在同步调用、任务预扣及按上游 credits 结算时都按倍率精确扣费，不再向上取整，例如 `5 × 0.5 = 2.5`；个人用户和平台管理员仍按原价，使用日志、积分流水、余额同步和失败返还均保留小数精度。企业列表新增倍率列后不会撑出页面级横向滚动，窄屏滚动限制在表格内部。
- Canvas 图片参考视频生成：第一方模型请求继续传递完整的 S3 预签名图片 URL；使用日志保留 `X-Amz-*` 查询参数名并将参数值显示为 `[REDACTED]`，不再显示成没有签名参数的裸 URL。
- 视频计费与 Vidu 日志：管理后台“私有配置 > 视频能力绑定”可在“计费规则”Tab 选择按 credits、按秒或按次计费；“公开配置 > 模型算力点”随绑定规则显示每 credit、各可选分辨率每秒或每次调用定价。绑定 ID 在视频工作台和第一方生成中都能正确路由到实际上游模型；按次/按秒在创建任务时预扣，按 credits 在成功响应后按上游消耗结算。账户使用日志、后台调用日志和响应详情展示 Vidu 上游 credits，缺失时明确显示 `null`。
- 单机蓝绿部署：生产入口迁移为稳定 edge Caddy，blue/green 运行准确 Git SHA 的配对 Web/API，部署前验证镜像与共享 JWT，内部 readiness 覆盖版本、API、数据库读取和旧 JWT；轮换 `JWT_SECRET` 时可显式勾选 `reset_sessions`，目标槽位必须在切流前通过新登录与新 JWT 验证。切流后公网失败自动回切，成功后排空并优雅停止旧槽位；手动 rollback 使用上一成功 SHA，普通发布不重启 PostgreSQL。首次生产启用时需记录双槽位资源峰值、实际排空耗时、普通发布旧 JWT 连续性、密钥轮换后的旧会话失效与新登录结果、旧槽位停止状态、PostgreSQL/edge 容器身份和手动回滚结果。
- 企业积分流水：企业主账号可在账户设置中分页查看带时间列的主账号和当前成员平台调整、企业分配/收回、AI 消费/退款流水，按成员、类型、关键词和日期范围组合筛选，并将当前筛选结果完整导出为 CSV；子账号仍仅能读取自己的个人流水，跨企业成员 ID、企业 ID 和关键词不能扩大查询范围。
- 企业文本素材库：有效企业的主账号和成员可分页搜索、按类型和标签筛选并预览本企业文本素材；主账号可新增、编辑和删除，成员只读，个人用户和跨企业账号无法读取或修改；企业素材不进入个人素材缓存、增量同步或 WebDAV。
- 企业媒体素材授权：主账号可上传、替换和删除本企业图片/视频素材及关联文件，主账号和成员可预览、读取和下载；个人文件与企业文件互不穿透，企业 A/B、个人用户、成员写入越权、猜测 ID、企业/成员停用和预签名 URL 均有 HTTP 集成覆盖，响应不包含原始 S3 Key。
- 企业素材服务端复制：企业主账号和成员可把文本、图片和视频加入“我的素材”；文本生成独立个人素材，媒体生成新的个人文件和个人素材，复制后的 `fileId` 不复用企业文件；跨企业/个人账号拒绝，源素材删除、企业停用后恢复或用户离开企业后个人副本仍可读，媒体复制失败或数据库事务失败不留下个人记录和对象。
- 企业积分划拨：企业主账号可在成员列表按正数分配或收回小数积分，并立即看到双方余额；相同请求 ID 只记账一次，余额不足、跨企业/非主账号操作、并发划拨、生成扣费竞争和事务失败均不会产生负数、超发或单边流水。
- 企业成员管理：企业主账号可在账户设置中分页搜索、创建、启用、禁用和重置本企业子账号密码；成员初始积分为零，禁用与密码重置立即作用于会话，子账号、个人用户、平台管理员和其他企业账号不能执行成员管理。
- 账号数据隔离：同一浏览器依次登录企业 A、企业 B 和个人账号时，Canvas、个人素材、同步游标、工作台历史及受保护查询不会展示上一账号数据；退出和认证失效同样立即清空内存视图。
- 企业基础管理：平台后台可创建和搜索企业、查看主账号/成员数/余额、分别切换企业与主账号状态并重置主账号密码；企业禁用立即拒绝全部成员会话，单独禁用主账号不影响成员，重置密码后旧 JWT 失效。
- 企业充值：平台管理员可在企业管理中按增量增加或扣减主账号积分，余额不足时不落库；余额与带原因、操作者和目标账号关联的流水在同一事务提交，企业页可立即核对余额和最近平台调整，用户列表显示企业归属与企业身份。
- 账户设置：头像菜单可进入账户设置，所有登录用户可查看用户名、积分和平台身份并修改昵称、邮箱和自己的密码；“日志记录”页签可分页查看当前账号自己的操作类型、来源、模型、状态、耗时、积分消耗和积分变动流水，按日期范围筛选使用记录与积分记录，并将当前筛选结果完整导出为 CSV，传入其他用户 ID 不能扩大查询范围或读取其任务详情；有效企业账号新增“企业信息”页签，企业概况迁移至该页签，企业主账号的成员管理和企业积分流水也仅在该页签展示，仅主账号可改企业名称；有效企业账号的桌面与移动导航显示“企业素材库”，个人账号直接访问时由服务端拒绝。
- Codex App 插件文档：新增插件安装教程，区分 AI 自动安装、手动安装和本仓库开发调试安装；同步优化插件 README 与技能说明。
- 配置与用户偏好：每个模型渠道新增 OpenAI / Gemini 调用格式选择，默认 OpenAI，切换默认格式时同步更新默认 Base URL；渠道 Tab 增加紧凑醒目的提醒，说明模型是否可选需要到“模型”Tab 选择。

- Gemini 调用格式：支持拉取 Gemini 模型列表，并用于文本问答、在线 Agent 工具调用、基础生图和图生图请求。
- 音频和视频生成：选择 Gemini 调用格式时先给出不支持提示，仍需使用 OpenAI 兼容渠道。
- 第一方视频生成：生成节点区分“排队中”和“生成中”，刷新或停止本地等待后可沿用同一平台任务恢复查询；异步失败保留可定位的设置或资源错误。
- Canvas 第一方视频观察恢复：临时网络或后端查询错误不会立即把本地节点写成任务失败；连续 20 次可重试错误后仅暂停本轮观察，并保留 task ID 或 client request ID。刷新或点击继续查询会重新向后端证实，创建响应丢失时找回原任务；已有平台 `fileId` 的成功视频继续直接展示，不再轮询。
- Canvas 生成任务等待：图片节点、第一方视频节点和本地兼容视频节点的前端观察时间由约 10 分钟延长至约 30 分钟；前端停止观察不会取消后端或上游任务，仍可沿用原任务恢复查询。
- Canvas 视频失败原因：第一方与兼容视频节点不再直接显示“操作失败”“后端服务失败”“后端服务未启用”或统一的“上游拒绝生成”；任务超时、任务过期、任务取消、状态同步超时、请求超时、限流、服务不可用、服务未配置、上游认证/权限、任务或接口不存在、内容安全审核、参数或输入无效、参考素材不可用、模型配置不可用及结果保存失败会显示各自的具体原因，连续查询失败暂停观察时也会显示可恢复的查询原因。未知供应商错误仍使用安全的上游失败说明。重点验证创建任务、轮询终态、恢复观察和本地直连四条路径。
- Canvas 视频时长：视频节点和视频配置节点的时长设置不再显示“智能”选项，视频工作台的现有时长选项保持不变。
- Canvas 视频配置：新建或切换为视频模式的配置节点中，“输出 - 生成声音”默认为关闭；手动打开后仍可保持开启。
- 生成任务可靠性：上游成功但缺少视频结果会稳定失败并一次退款；回调、轮询、取消和超时不会覆盖已进入结算或终态的任务。
- 图片生成：共享图片设置新增透明背景开关，同步生成、同步编辑、Canvas 异步生成/编辑和 Retry Run 均按本次 Generation Run 快照传递；Resume Observing 不重复提交。
- Canvas Prompt：普通节点支持文本与资源 chip 混合编辑，保留原有字符串标签、active resource 顺序和连接关系，并支持 IME、纯文本粘贴、原子删除、撤销重做及键盘资源菜单。
- Canvas 节点发送快捷键：节点提示词输入框改为回车换行、`Shift+Enter` 发送，避免普通回车误触生成。
- Canvas 视频资源引用：视频节点连接到其他节点后，在提示词输入框输入 `@` 时，候选项和插入后的资源 chip 使用对应视频节点的同一视频地址显示首帧，不再出现破碎图片。
- Canvas 节点输入：提示词与配置编辑器中的资源 chip 使用真实 DOM 排版，后续文字、换行和粘贴内容的光标紧贴实际字符；文字节点使用单一原生 textarea，不再叠加会与真实 caret 产生宽度差的高亮镜像层；节点提示词输入框可正常使用滚轮上下滚动，且不会触发画布缩放。
- Canvas 节点输入放大：节点提示词输入框右下角新增放大/缩小按钮；插入 `@` 资源后切换尺寸会保持焦点和光标选区，缩小后继续保留完整内容并用于后续生成请求。
