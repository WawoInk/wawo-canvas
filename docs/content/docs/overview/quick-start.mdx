# 快速开始

## Docker compose 部署（推荐）

完整的后端 + 前端 + PostgreSQL 一键启动：

```bash
git clone git@github.com:basketikun/infinite-canvas.git
cd infinite-canvas
docker compose up -d
```

启动后访问：

```text
http://localhost:3000
```

首次使用请进入后台注册管理员账号，然后配置 AI 渠道和算力点。

## 本地前端启动

如果你只需要前端（浏览器直连模式，不计费）：

```bash
git clone git@github.com:basketikun/infinite-canvas.git
cd infinite-canvas/web
bun install
bun run dev
```

启动后访问：

```text
http://localhost:3000
```

## 首次使用建议

- 如果使用 Docker compose 部署：注册管理员账号 → 后台配置 AI 渠道 → remote 模式使用。
- 如果使用本地前端启动：打开右上角配置弹窗，填入自己的 `Base URL`、`API Key` 和模型名。
- 如果需要提示词仓库内容，打开 `/prompts` 会通过 Next.js route 拉取并缓存在内存中。
- 如果需要跨设备同步画布、素材和生成记录，可在配置弹窗中填写 WebDAV。

## 说明

- 当前画布项目和"我的素材"主要保存在浏览器本地，WebDAV 同步需要用户自行配置。
- AI API Key 保存在浏览器本地，并由前端直接请求 OpenAI 兼容接口。
